A complete, original entry for the [One Star, Five Stars for the Food](https://make.fun/bounty/u-po-pu-one-star-five-stars-for-the-food-f9166ee7) bounty on make.fun: one sentence, at most 200 characters, in the voice of an alien tourist giving planet Earth a one-star review while still slipping in a real compliment about the food.

## The review

> One star: Earth makes you pay for water, charges extra for legroom, and invented small talk — but the ramen was so good I briefly considered defecting.

151 characters. The program (`main.ts`) writes exactly that sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` in the grading sandbox).

## How it runs

```sh
node main.ts
```

Node 22 or later, no dependencies, no network, no build step.
